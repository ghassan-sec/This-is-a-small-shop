Title: Project Creation
Project Description:
To begin with, I opened Visual Studio Code and used Python to create the project. I spent about fifteen minutes brainstorming ideas until I came up with the concept of a management system for a shoe store, which I started implementing immediately. First, I printed a welcome message ("Welcome to the Golden Shoes"), and next, I began writing the code for the invoice details, including the username (saved to a file), shoe type, size, color, and price.
Furthermore, I added three color options (Black, White, and Brown)—with black as the only available color—meaning the system proceeds if black is selected and closes with a welcome message otherwise. I also categorized the shoes into three priced types (Sports at $50, Sandals at $30, and Formal at $70) so that once the color, type, and size are selected, a complete invoice and welcome message are printed, which I successfully tested.
Challenges Faced:
I faced some difficulties with implementing certain terms and organizing the layout, particularly forgetting to include the price initially before realizing the invoice was incomplete and adding the pricing functionality.
Key Takeaways & Benefits:
This project helped me develop my programming skills and knowledge, increasing my expertise day by day and giving me a solid understanding of how to build projects.
